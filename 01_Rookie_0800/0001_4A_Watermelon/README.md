## 📖 Description

Pete and Billy bought a watermelon weighing **w** kilograms.

They want to divide it into **two positive even parts**.

Determine whether such a division is possible.

---

## 📥 Input

The first line contains a single integer **w** *(1 ≤ w ≤ 100)* — the weight of the watermelon.

---

## 📤 Output

Print:

- ✅ `YES` — if the watermelon can be divided into two positive even parts.
- ❌ `NO` — otherwise.

---

## 💡 Example

### Input

```text
8
```

### Output

```text
YES
```

---

## ⚙️ Constraints

```text
1 ≤ w ≤ 100
```
